# Benchmark Results - 2026-11-08

Environment: `qwen3.5:4b-mtp` (Q4_K_M, Vulkan, llama-server b12001), HiveMind
dev tree, Aider 0.86.2 in a separate venv. Same model and server for every
condition; hidden tests; fresh workspace per cell.

## Phase 1 - Harness smoke

| Condition | Tasks | Pass | Duration | Tokens |
|---|---:|---:|---:|---:|
| `raw` (diff) | 2 | 0/2 | 5.5 / 12.9 s | 334 / 781 |
| `raw_files` | 2 | 2/2 | 3.5 / 6.3 s | 680 |
| `hivemind_direct` | 2 | 2/2 | 25.5 / 20.3 s | 15,559 / 21,273 |
| `hivemind_duo` (planner on) | 1 | 1/1 | 52.0 s | 68,478 |
| `aider` | 1 | 1/1 | 10.4 s | 833 |

The smoke found and fixed three measurement bugs:

1. `hivemind_direct` posted `mode="chat"`, which the engine does not know
   (recognized: auto|automap|simple|pipeline|agent|code_duo). Fixed to
   `mode="simple"`.
2. HiveMind conditions used the install's settings models instead of
   `--model`. Requests now force `direct_model` and all duo role overrides.
3. Tool loops discarded the server `usage` blocks, so a tool run reported
   ~0 tokens. `ToolLoopState` now sums prompt/completion/cached per round;
   the direct route emits `usage_meta`; the benchmark sums it.

## 21-task run (3 runs per condition)

21 tasks: 9 bugfix, 5 feature, 3 refactor, 4 multi-file.

| Condition | Cells | Pass | 95% CI | Median | Tokens/cell |
|---|---:|---:|---|---:|---:|
| `raw` (diff) | 63 | **0%** | [0, 6] | 7.2 s | 670 |
| `raw_files` | 63 | **71.4%** | [59, 81] | 5.4 s | 419 |
| `aider` | 63 | **90.5%** | [81, 96] | **12.0 s** | **946** |

### Paired comparisons (21 tasks, majority verdict)

| Pair | A only | B only | McNemar p |
|---|---:|---:|---:|
| aider vs. hivemind_direct | 1 | 2 | **1.00** |
| aider vs. hivemind_duo | 1 | 2 | **1.00** |
| hivemind_direct vs. hivemind_duo | 0 | 0 | **1.00** |
| aider vs. raw_files | 4 | 0 | 0.125 |
| hivemind_direct vs. raw_files | 5 | 0 | 0.0625 |
| raw vs. raw_files | 0 | 15 | 0.0001 |

**Quality:** no measurable difference between Aider, Direct and the coder on
this corpus. Direct and the coder solve the same 20/21 tasks. Both are
~20 percentage points above the no-tool baseline; the McNemar test is not
significant for that gap at 21 tasks (p = 0.06/0.13), but the direction is
clear.

| raw_files | 0.89 | 0.60 | 0.50 | 0.67 |

- Direct/coder win the feature tasks (`feature_parse_bool`,
  `feature_word_freq`: 2/3 vs. Aider 0/3).
- Aider wins multi-file (`multi_config`: 3/3 vs. 1/3).
- The only shared HiveMind failure is `multi_config` (`test_backward_constant`).
- Category cells are small (3-9 tasks); these are hints, not rankings.

### Cost

- Direct: ~22x Aider tokens, 1.6x wall time.
- Coder-alone: ~114x Aider tokens, ~5x Direct, 4.9x Aider wall time.
- On small tasks the tool loop is pure overhead; it must earn its cost on
  larger/ambiguous tasks.

## Corrections

- The earlier 6-task run reported duo 0%. The cause was
  `duo_tool_rounds=0` in the install settings: the coder ran **without
  tools**. After pinning the shipped default (50), the 4B coder works
  (2/2 smoke, 20/21 in the corpus). The earlier "4B duo is not viable"
  statement was a measurement error.
- Token numbers are not identical units: HiveMind sums prompt+completion for
  every tool round; Aider's figure is its own sent/received report. See
  [TOKEN_EFFICIENCY.md](TOKEN_EFFICIENCY.md).

## Limitations

- 21 synthetic tasks and one 4B model; no claim about 35B or real repos.
- 3 runs per cell for raw/raw_files/aider/direct; 1 run for coder-alone.
- Aider sees the same files but uses a different edit strategy; same model,
  not same agent.
- The starter tasks are small; they likely understate the value of
  exploration/verification on real multi-file work.
- The coder run used the **pre-core full tool set**. The new default is
  `duo_core` (16 tools); the next run should pin `duo_coder_tool_tier` per
  condition and compare core vs. full on pass rate and churn.

## Conclusion

1. On the starter corpus, HiveMind does not beat Aider in quality; it matches
   it at much higher token cost.
2. All agent conditions clearly beat the no-tool baseline (71% -> 90-95%).
3. Direct and the coder are complementary to Aider by category: HiveMind is
   stronger on feature tasks, Aider on multi-file.
4. The next meaningful test is 5-10 real-repository tasks, optionally with
   35B; only there can the tool loop's exploration/verification pay off.
